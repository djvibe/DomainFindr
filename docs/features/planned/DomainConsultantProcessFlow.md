# Domain Consultant Process Flow

## Goal

Define the start-to-finish process for using `DomainFindr` as a domain strategy and naming consultant, not just a lookup utility.

## Start-To-Finish Workflow

### 1. Gather the brief

Capture:

- business model
- launch wedge
- long-term platform ambition
- preferred naming styles
- geography
- budget
- registrar preference

### 2. Define naming lanes

Group ideas into a few strategic lanes:

- directory / category
- authority / editorial
- data / ranking
- software / platform
- coined startup brand

### 3. Generate candidate names

Create batches with:

- exact-match priority names
- exact-root alt TLDs
- clean `.com` alternatives
- branded fallback `.com` variants
- coined brandables

### 4. Run broad availability sweep

Use `DomainFindr` to screen large candidate sets quickly.

Desired output:

- available
- registered
- timed out
- invalid

### 5. Retry and verify

Retry:

- timeouts
- high-interest misses

Then recheck shortlisted names with registrar-aware availability and pricing when possible.

### 6. Evaluate quality, not just availability

For each serious candidate, assess:

- clarity
- premium feel
- memorability
- category fit
- company-brand fit
- SEO/direct-response fit
- expansion potential
- pricing realism

### 7. Build the recommendation set

Always produce:

- best startup/software brand
- best directory/media brand
- best authority/ranking brand
- best clean `.com`
- best wildcard or coined brand

### 8. Produce decision-ready output

Final artifacts should include:

- executive summary
- full report
- buy-now recommendation
- skip list
- next-step acquisition guidance

## Operational Rules

- trust registrar checkout over RDAP for buying decisions
- separate premium domains from hand registrations
- avoid weak prefixed `.com` domains unless there is a strong reason
- prefer exact-root alt TLDs over awkward `.com` compromises when the brand quality is materially better
- keep local research in `workspace/`
- store durable lessons in tracked docs

## Recommended Output Structure

Tracked:

- `docs/domain_research_lessons.md`
- `docs/features/planned/`

Local:

- `workspace/batches/in/`
- `workspace/batches/done/`
- `workspace/results/<friendly-session-folder>/`
