# Spa Platform Domain Strategy

## Overview
You are building a platform that evolves through three phases:

1. **Authority / Media**
   - Top 100 spa lists
   - Wellness score
   - Blog + SEO

2. **Tools / SaaS**
   - Analytics for spa owners
   - Marketing tools
   - Visibility + ranking dashboards

3. **Marketplace**
   - Booking
   - Payments
   - Distribution

This means the brand must scale from **content → data → platform → marketplace**.

---

### Key Rules

- Low syllables (2–4 max)
- Easy to spell + type
